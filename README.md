
# KanchanFlow — Industrial Workflow Landing Page

A modern, responsive marketing website for KanchanFlow, featuring an industrial-modern design with dark graphite backgrounds, gold accents, and clean layouts.

## ✨ Features

- **Home Page** — Hero section, dashboard preview, product highlights, and call-to-action sections.
- **Features Page** — Overview of the product's key capabilities.
- **Pricing Page** — Starter, Growth, and Enterprise pricing plans.
- **Monthly/Yearly Toggle** — Switch between billing options.
- **FAQ Accordion** — Expandable answers to common questions.
- **Responsive Navbar** — Navigation links and mobile-friendly menu.
- **Responsive Design** — Layouts adapted for mobile, tablet, laptop, and desktop.
- **Reusable Components** — Consistent UI elements and styling.
- **SEO Metadata** — Page-specific metadata for search engines.

## 🛠️ Tech Stack

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the project directory

```bash
cd kanchanflow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📱 Responsive Design

The website has been tested at these viewport widths:

- 375px — Mobile
- 768px — Tablet
- 1024px — Laptop
- 1440px — Desktop

## 🧪 Production Build

Run the following command to create an optimized production build:

```bash
npm run build
```

The production build completed successfully during local validation.

To run the production build locally:

```bash
npm run start
```
